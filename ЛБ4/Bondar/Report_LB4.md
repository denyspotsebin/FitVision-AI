# ЗВІТ З ЛАБОРАТОРНОЇ РОБОТИ №4
**Виконав:** [Бондар Артем]

## 1. Тема та мета лабораторної роботи
**Тема:** Статичний аналіз коду, Code Review та рефакторинг.
**Мета:** Опанувати інструменти статичного аналізу (лінтери), навчитися проводити взаємний огляд коду (Code Review) для виявлення code smells, а також виконати рефакторинг власного коду з подальшим регресійним тестуванням.

  | № | Рядок коду | Проблема | Категорія | Рекомендація |
| :--- | :--- | :--- | :--- | :--- |
| 1 | Умова з числами 30 та 250 | Використання магічних чисел та помилка межі (`<= 30`) | Magic Numbers / Boundary Logic Error | Винести 30 та 250 у константи (`MIN_WEIGHT`, `MAX_WEIGHT`) та змінити умову на `< 30`. |
| 2 | Класи `BasePhoto`, `AIGeneratorService` | Розміщення кількох класів в одному файлі `Program.cs` | Multiple Classes in One File | Винести кожен клас в окремий файл згідно з конвенціями C#. |
| 3 | Метод повертає `bool`, але кидає `Exception` | Змішування повернення значень та генерації винятків | Exceptions for Control Flow / Misleading Signature | Змінити тип повернення на `void` або прибрати `throw` на користь повернення `false`. |
| 4 | `public int UsedRequests { get; set; }` | Публічний сеттер для ліміту запитів | Broken Encapsulation | Змінити на `{ get; private set; }`, щоб оминати зміну лімітів ззовні. |
| 5 | Тексти повідомлень про помилки в коді | Текстові дані захардкоджені в методах | Magic Strings | Винести повідомлення у файл ресурсів або константи класу для локалізації. |
